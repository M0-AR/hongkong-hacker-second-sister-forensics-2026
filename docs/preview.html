🌱 Beginner guide — read this and you are a professional

You will know more than most interview candidates. Let's work this out in a step-by-step way to be sure we have the right answer.

Step 0 — The story in 30 seconds. A schoolgirl is harassed on the train. A stranger is blamed. An anonymous post pretends to be the stranger's nephew. A pile-on follows. Her sister hires hacker N to find who really wrote it. We verify N's methods, not the plot.
Step 1 — What is an IP + Tor relay? An IP is a return address. A relay is a forwarder that hides it. If any forwarder keeps no notes, the trail ends. That is why N says tracing is “a needle at the bottom of the ocean”. Try: python3 experiments/01_tradecraft_verification.py and look at E1_popcorn_relay.
Step 2 — E-mail headers don't lie (much). Every mail carries Received: stamps + X-Mailer:. Three Hong Kong stamps in 9 minutes + iPhone mail = someone moving between train stations, not a foreign hacker. Open src/forensics/email_forensics.py.
Step 3 — Photos remember. EXIF stores date + GPS. The karaoke photo says Christmas Eve near King Wah Centre — the exact night two classmates walked the victim home. Metadata can be faked, so treat it as a clue, not proof.
Step 4 — Wi-Fi whispers. Phones shout “any network here?” (probe requests) leaking a hardware ID (MAC). A fake network with a stronger signal can sit in the middle (MITM) — like a fake library counter handing you altered books. Modern phones randomise MACs, so MAC ≠ person.
Step 5 — Bullying is a session. One insult = rude. Ten messages targeting one person + power gap + repetition = bullying. That is why we group texts by session and measure bursts, not single sentences.
Step 6 — Measure right. On skewed data, accuracy lies. Report F1 + PR-AUC. Our tiny demo hits F1 0.80 / PR-AUC 0.93. On 47k real tweets, transformers reach ~0.93+.
Step 7 — Go pro. Swap in public data, run make all, read PAPER.md, extend to BERT. You now beat most “I did sentiment analysis” portfolios.

❓ FAQ (even a first-timer understands)

Do I need to read the novel? No. The beginner guide + quiz cover everything. The code uses short paraphrases, never full chapters.

Is this hacking illegal? No. We only parse sample headers/metadata and simulate defences. No interception, no exploits, no real devices.

Why is accuracy not enough? If 99% of comments are nice, a lazy “always nice” model scores 99% accuracy and catches zero bullying. F1 + PR-AUC punish that.

Can MAC address identify a person? No — modern phones randomise it. N's leap is flagged as dramatic licence in EXP-01.

What if I have zero Python? Install Python 3.12, run the 3-line quickstart. The quiz teaches the ideas first.
